# Task: review a profile cache

A teammate opened a pull request that adds `profile-cache.mjs`. It caches user profiles in
memory, shared by every request, so the profile page loads faster.

Write a short code review. For each problem you find, say what goes wrong, when it would
happen, and what you would change. Rank the problems from most to least serious. You do not
need to run the code.

When you think your review is complete, hand it to the observer. They will check it against a
fixed list and only say "complete" or "not yet". You may keep going within the time limit.
